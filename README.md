# 💫 About Me
# Hi, I'm Nayansi Dupare 👋

**Full-Stack Developer | AI/NLP Systems | React · Node.js · Python · FastAPI**

I'm an MCA student and Software Developer at **Fastship**, where I build scalable web application modules and REST APIs using React.js and Node.js/Express.js in an Agile/Scrum environment.

I enjoy working at the intersection of full-stack development and applied AI — building products that use LLM APIs (OpenAI GPT-4o) alongside traditional NLP tooling like spaCy, NLTK, and scikit-learn.

---

## 🚀 What I'm building

- **[AutoApply](https://autoapply.in/)** — A platform that lets users apply to jobs in one click, check their resume's ATS score, edit their resume with an AI-powered editor, and get personalized job recommendations based on their skills. Built with React and Next.js.
- **Marshall Haber Creative Group** — Contributed to the frontend build of [marshallhaber.com](https://marshallhaber.com), implementing GSAP-powered scroll animations and a fully responsive layout.
